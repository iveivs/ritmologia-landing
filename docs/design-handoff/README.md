# Handoff: лендинг школы барабанов «Ритмология»

## Overview
Одностраничный лендинг школы ударных в Санкт-Петербурге. Главная цель — запись на бесплатный пробный урок (форма в тёмной полосе «Запись»), второстепенная — продажа разовых занятий и абонемента, плюс онлайн-занятия для тех, кто не в Петербурге.

## About the Design Files
Файлы в этом пакете — **дизайн-референс, сделанный в HTML**: прототип, показывающий финальный вид, копирайт и поведение. Это не production-код для прямого копирования. Задача разработчика — **воссоздать этот дизайн в целевой кодовой базе** (Next.js/React, Vue, Astro, Tilda-like CMS — что используется в проекте), опираясь на её паттерны, роутинг, сборку и компонентную библиотеку. Если кодовой базы ещё нет, выберите подходящий стек (для статического лендинга разумно Next.js или Astro) и реализуйте дизайн там.

`Landing.dc.html` открывается в браузере как есть (двойной клик) — используйте его как эталон вида и поведения. Разметка внутри него инлайновая и намеренно плоская; в проде выносите значения в токены/классы.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, состояния и вся копия — финальные. UI нужно воспроизвести пиксель-в-пиксель на 1240px контейнере. Копирайт менять нельзя без согласования с заказчиком.

## Interactions & Behavior
- **Навигация:** все CTA («Бесплатный урок», «Попробовать онлайн бесплатно», кнопки в ценах) ведут на `#booking` со smooth-скроллом.
- **Карусель отзывов:** кнопки ‹ › скроллят контейнер на ширину карточки (`scrollBy` с `behavior: smooth`); snap по началу карточки; свайп работает нативно.
- **Hover:** только смена цвета, без масштабирования. Красный → `#A81F16`, ink → `#221A15`, outline-кнопка инвертируется в ink-заливку, ghost-кнопка краснеет. Фото внутри `PersonCard` — `scale(1.03)` за 560ms.
- **Press:** `translateY(1px)` + затемнённый красный.
- **Focus:** `outline: 2px solid #C62A1E; outline-offset: 2px` — не удалять.
- **Motion:** цвет 120ms, движение 200ms, аккордеон 320ms, изображения 560ms; easing `cubic-bezier(.2,.7,.2,1)`. Всё обнуляется при `prefers-reduced-motion`.
- **Форма записи:** валидация — имя не пустое, телефон/мессенджер не пустой, чекбокс согласия обязателен. Ошибка — текст 15px под полем, подчёркивание краснеет. Успех — заменить форму на короткое подтверждение («Заявка отправлена, напишем в мессенджер»), без модалок. Отправка бэкенда в прототипе не реализована: подключите реальный endpoint/CRM.
- **Адаптив:** двухколоночные сетки складываются в одну колонку ниже ~900px (порядок: текст выше фото), сетка 2×2 в «Чему учим» — в одну колонку ниже ~640px, карточки цен переносятся автоматически. Фиксированных высот у текстовых блоков нет.
- **Никаких** sticky-CTA, плавающих чатов, параллакса и скролл-джекинга.

## Design Tokens
Цвета:
- `--cream-100 #F5EBE1` — фон страницы
- `--cream-200 #EEDFD2` — чередующаяся полоса
- `--cream-50` — приподнятые карточки
- `--ink-900 #17120F` — текст, тёмная полоса; `#211A16` — бар «окна»; `#3C322B` — body-текст; `#6B5C52` — вторичный/лейблы; `#E4CDB9` — caps-лейбл на тёмном
- `--red-500 #C62A1E` — акцент, действия, mono-индексы; hover `--red-600`, press `--red-700`
- Hairline `rgba(23,18,15,.12)`; на тёмном `rgba(245,235,225,.22)`

Типографика: `Golos Text` (400/500/600/800) + `JetBrains Mono` для цифр, цен, телефонов и индексов.
- Hero: 800, `clamp(2.6rem,6vw,6rem)`, lh 1.14, ls −.005em, uppercase
- H2: 800, `clamp(1.8rem,3.4vw,2.6rem)`, lh 1.05, ls −.005em, uppercase
- Лид: 19px / 1.55, мера 46ch (адрес — 30ch)
- Body: 15px / 1.55, мера 52–56ch
- Caps-лейбл: 13px, 600, `letter-spacing .22em`, uppercase
- Mono: 13px, `letter-spacing .04em`

Отступы: контейнер 1240px, гаттер 24px, секция 112px (в ДС `--section-y: clamp(72px,10vw,140px)`), внутренние гэпы 12/16/24/32/56/64px.
Радиусы: 2px кнопки, 4px карточки и фото, pill только для `Tag`. Радиусы 16/20/24px — только у мокапов устройств.
Тени: покоя нет; hover-карточка `0 12px 32px -18px rgba(23,18,15,.28)`; мокапы устройств — см. секции 04 и 05.
Границы: 1px hairline, 1.5px кнопки и подчёркивания полей, 2px правило над блоком.
