# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии —
[SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено

- Единый стандарт UX/UI (`docs/DESIGN-STANDARD.md`) и правила кода
  (`docs/ENGINEERING.md`), правила работы с GitHub (`CONTRIBUTING.md`).
- UI-аудит `npm run audit:ui`; Prettier и EditorConfig; CI на pull request;
  шаблоны PR и issue; Dependabot; CODEOWNERS.

### Изменено

- Секции «Дневник» и «Личный кабинет» объединены в «Для учеников»: общий заголовок и два ряда (дневник Beat by Bit со ссылкой, кабинет «Тьюттори» с кнопкой «Войти»); нумерация и чередование фонов пересчитаны, зебра FAQ и карточки отзывов подстроены под новый фон.
- Первый экран: постер сохраняет высоту 536 px при коротком тексте, колонка постера уже (7/5), заголовок крупнее; текст выровнен по верху, кнопка на первом экране.
- Первый экран: заголовок «Уроки барабанов», надстрочник «Санкт-Петербург · и онлайн», лид про любимые песни и подпись «Первый урок — бесплатно · 30 минут» (вместо слогана «Думай чувствуй играй»); обновлены title и description страницы.
- Эффекты: построчное появление заголовка («Чему учим»), каскад карточек, «играющие» полоски в подвале, zoom фото при наведении, шкала прокрутки, кнопка «Наверх» в конце страницы.
- Секция «Личный кабинет» перевёрнута (телефоны слева), чтобы не повторять композицию «Дневника»; UI-аудит проверяет чередование композиций.
- Группы однородных элементов (чему учим, пункты тарифов, отзывы, вопросы)
  размечены семантическими списками `ul/ol`.
- Цифры в пунктах тарифов выровнены по базовой линии текста.

## [1.0.0] — 2026-10-11

Первый полный выпуск лендинга.

### Добавлено

- Лендинг на Next.js со статическим экспортом: секции «Чему учим», «Студия»,
  «Преподаватель», «Онлайн», «Дневник», «Личный кабинет «Тьюттори»», «Отзывы»,
  «Цены», «Вопросы», «Адрес», «Запись».
- Система токенов (палитра → роли → шкалы), сторож токенов в линте и CI.
- Светлая и тёмная темы (системная + ручной выбор), чередование фонов секций.
- FAQ с разметкой schema.org, карта по клику, готовые сообщения в Telegram.
- Доступность: ссылка «Перейти к содержимому», `<main>`, зоны нажатия 44 px
  на телефоне, контраст AA в обеих темах.
